## Getting started

Requires [just](https://github.com/casey/just).

```sh
just          # list tasks
just check    # lint, typecheck, test
just dev      # run locally
```

Contributor and agent conventions are in [AGENTS.md](AGENTS.md). Decisions are recorded in
[docs/adr/](docs/adr/).
